# Contributing

Ideas, bug reports and fixes are welcome.

- **Found a problem?** [Open an issue](https://github.com/R3disme/jotiglobe/issues/new) and say which page and
  browser.
- **Want to change something?** Fork the repository, make your change on a branch and open a pull request. Run
  `pnpm check` and `pnpm build` first.

A few things the site promises its visitors, so changes need to keep them:

- Nothing is loaded from other websites: no CDNs, external fonts, analytics or trackers.
- No cookies, and no personal data about visitors. Usage statistics stay anonymous and optional.
- Only the public fields listed in [data](data.md) are taken from the directory.
- It keeps working on slow, old machines and without JavaScript for the plain pages.

By contributing you agree that your changes are published under the project's [licence](../LICENSE).
